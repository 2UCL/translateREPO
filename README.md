# Translate of R.E.P.O. (ja-jp)
Steamにて公開されているゲーム [R.E.P.O.](https://store.steampowered.com/app/3241660/) の、日本語翻訳パッチです(非公式)。

MOD不要で導入できます。

## TL;DR
(いそいでいる人向け)
```
(R.E.P.O.のインストール先)\REPO_Data\StreamingAssets\Localizations\
```
の中に `ja.zip` の中身を解凍してぶち込んでください


# インストールガイド
1. [Releases](https://github.com/2UCL/translateREPO/releases/latest) から最新の `ja.zip` をダウンロード

1. ダウンロードした `ja.zip` を [すべて展開] で展開する
![](/img/unzip.png)

1. Steamを開いて [ライブラリ] → [R.E.P.O.] を右クリック → [管理 >] → [ローカルファイルを閲覧] の順にクリック
![](/img/path0.png)

1. エクスプローラーが開くので、[REPO_Data] → [StreamingAssets] → [Localizations] の順にフォルダを開く

![](/img/path1.png)

　↓

![](/img/path2.png)

　↓

![](/img/path3.png)

5. 開いたフォルダの中に、2.で展開した `ja` フォルダの中身 (readmeはなくてもOK) を移動する
![](/img/path4.png)

1. 完了
